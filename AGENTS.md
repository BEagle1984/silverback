# Repository guidance

## Temporary investigation files

- Put ad hoc investigation notes, test-run summaries, scratch scripts and temporary exports in the repository's top-level `temp/` directory.
- Give each file a meaningful name including the current date: `YYYY-MM-DD-description.ext`, for example `2026-09-17-kafka-rebalance-findings.md`.
- `temp/` is ignored by Git. Do not commit or force-add these files, add them as Solution Items, or create permanent documentation links to individual temporary files.
- Keep maintained documentation in its normal location. Existing test and tool output directories remain appropriate for artifacts generated by those tools.
