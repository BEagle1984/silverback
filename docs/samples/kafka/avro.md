# Kafka - Avro

This sample implements a producer and consumer which take advantage of the schema registry and serializes the messages as Avro.

## What This Sample Shows

- Enabling the Confluent schema registry integration with `AddConfluentSchemaRegistry`.
- Using a message class generated by `avrogen` from the `AvroMessage.avsc` schema.
- Registering the schema for the `samples-avro-value` subject at startup through the `IConfluentSchemaRegistryClientFactory`.
- Serializing with `SerializeAsAvro`, disabling the automatic schema registration and using the latest registered version.
- Deserializing with `DeserializeAvro`.

## How to Run

Start the infrastructure as described in <xref:samples> (the schema registry is required, listening on `localhost:8081`), then run the two applications from the repository root.

```bash
dotnet run --project ./samples/Kafka/Avro.Producer/.
dotnet run --project ./samples/Kafka/Avro.Consumer/.
```

Observe the console output while the messages are produced and consumed.
