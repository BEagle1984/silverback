StopAsync(IBrokerMessageIdentifier, bool)

Requests that the consumer stop because processing the specified message failed.

ValueTask StopAsync(IBrokerMessageIdentifier brokerMessageIdentifier, bool waitUntilStopped = true)

Parameters

brokerMessageIdentifier IBrokerMessageIdentifier

The original identifier from the received message that caused the stop request.

waitUntilStopped bool

Whether to wait for message processing to finish. Pass false when calling from message processing to avoid waiting for the calling operation itself.

Returns

ValueTask

A ValueTask representing the stop request. If waitUntilStopped is true, accepted stop requests also wait for message processing to finish.

Remarks

The original message identifier allows the broker implementation to ignore obsolete stop requests. For example, delayed error handling for a Kafka message from an earlier partition assignment must not stop consumption after reassignment. Use StopAsync(bool) to stop unconditionally.

StopAsync(bool)

Stops the consumer without disconnecting. Can be used to pause and resume consuming.

ValueTask StopAsync(bool waitUntilStopped = true)

TriggerReconnectAsync()

Stops the consumer and starts an asynchronous Task to disconnect and reconnect it.

ValueTask TriggerReconnectAsync()

Returns

ValueTask

A ValueTask representing the asynchronous operation. This ValueTask will complete as soon as the stopping signal has been sent, while the process will be completed in another asynchronous Task.

Remarks

This is used to recover when the consumer is stuck in state where it's not able to rollback or commit anymore.
