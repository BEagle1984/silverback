DefaultPartitionsCount

Gets or sets the default number of partitions to be created per each topic. The default is 5.

int DefaultPartitionsCount { get; set; }

Property Value

int

OverriddenAutoCommitIntervalMs

Gets or sets the auto-commit interval in milliseconds to use in mocked consumers instead of AutoCommitIntervalMs. The override is applied automatically and defaults to 50 milliseconds. Set it to null to use the consumer's configured interval, or 5 seconds if no interval is configured.

int? OverriddenAutoCommitIntervalMs { get; set; }

Property Value

int?

Remarks

This override only affects consumers with auto-commit enabled and speeds up tests that wait for broker offset commits. WaitUntilAllMessagesAreConsumedAsync(params string[]) uses locally stored offsets and does not depend on this interval.
