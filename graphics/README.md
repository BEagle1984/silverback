# Silverback graphics

The SVG files are the masters; all PNG and ICO files are exports of them. The previous artwork is archived in `old/`.

## Marks

| File | Use |
| --- | --- |
| `icon.svg` | Main icon: white head on a black rounded square. Avatars, NuGet, favicons. |
| `icon-mono.svg` | One-colour icon, head knocked out of the square. Printing, engraving, single-colour contexts. |
| `badge.svg` / `badge-mono.svg` | Circular variants for stickers, pins and other merchandise. |
| `logo.svg` / `logo-white.svg` | Horizontal lockup (one colour) for light and dark backgrounds. |
| `logo-stacked.svg` / `logo-stacked-white.svg` | Stacked lockup for square formats. |

`icon.png` (256 px) is the NuGet package icon and `icon.ico` is the Windows application icon. Additional sizes are in `exports/`.

## Guidelines

- Keep the logo monochrome. On dark backgrounds use the white variants; don't add outlines or shadows.
- Leave clear space around the marks of at least a quarter of the icon height.
- Don't stretch, rotate or recolour parts of the mark independently.

## Typography

The wordmark is set in JetBrains Mono ExtraBold (SIL Open Font License) with -0.02 em tracking, converted to outlines, so no font is needed to use the files. The documentation site uses the same family for code.
